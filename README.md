Local RAG Assistant (Microsoft Foundry Local)
An offline, secure document question-answering (RAG) assistant running entirely on your device without requiring an internet connection or Azure.

🚀 Features & Capabilities
Fully Local Execution: Operates independently of cloud services using the Microsoft Foundry Local SDK framework.

Smart Chunking: Splits documents into manageable pieces while maintaining semantic integrity (configured via CHUNK_MAX_CHARS and CHUNK_OVERLAP_CHARS).

Vector Search & SQLite Storage: Embeddings generated by the qwen3-embedding-0.6b model are stored and searched using cosine similarity within an SQLite database (data/rag.db).

Hallucination Protection: Enforced by the phi-3.5-mini chat model and strict system prompt guidelines, ensuring missing information is never fabricated and safely returns a fallback message ("Bu bilgi belgelerimde bulunmuyor.") instead.

Error Handling: Built with robust try-except mechanisms to handle local timeout and operation cancellation issues (Operation was cancelled).

Gradio Interface: Provides a user-friendly web-based chat interface.

🛠️ Tech Stack
Python 3.12

Microsoft Foundry Local SDK (phi-3.5-mini & qwen3-embedding-0.6b)

Gradio (Web UI)

SQLite (Local Database)

⚙️ Installation & Usage
Follow these steps to set up and run the project locally:

Navigate to the Project Directory:

Bash
cd microsoft_proje
Create and Activate a Virtual Environment:

Bash
python -m venv .venv
For Windows:

Bash
.\.venv\Scripts\activate
Install Required Packages:

Bash
pip install -r requirements.txt
Process Data and Build the Database:

Bash
python ingest.py
Start the Application:

Bash
python app.py
Open the local URL provided in the terminal (e.g., [http://127.0.0.1:7860](http://127.0.0.1:7860)) in your browser to start using the assistant.
